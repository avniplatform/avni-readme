After syncing is completed for the first time, new field users often don't know what to do next. This leads to additional effort in the field to manually guide users and inform them that they need to start registering beneficiaries. To avoid this, Avni now provides a built-in tooltip that automatically guides users towards the Register button on their first login.

## How to Enable

1. Log in to the Avni webapp as an admin.
2. Navigate to the **Organisation Details** page <Anchor label="here" target="_blank" href="https://app.avniproject.org/#/admin/organisationDetails">here</Anchor>
3. Toggle on **"Guide users to Register button"**.

   <Image align="center" src="https://files.readme.io/54dadeb6f8b365a57f0fe015ff0b8376271b691a3ee9b33de84bdbea393975cd-webapp.png" />

   <br />

## How It Works

Once enabled, when a user signs in for the first time on the mobile app, a tooltip will appear highlighting the **Register** button. This tooltip guides the user to take their first action — registering a beneficiary — without needing any external instruction or training.

<Image align="center" width="200px" src="https://files.readme.io/49d36b455e872fe974369d8a8a88943ca1a35a71232e76c8f0db99511bbf264c-register.gif" />

<br />

## Key Points

* The tooltip is shown **only on the first login** after sync is completed, so it does not interrupt experienced users.
* This is an organisation-level setting — once enabled, it applies to all users in the organisation.
